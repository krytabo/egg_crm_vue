# 後端溝通紀錄 2026-04-17

## 1. 請後端補上 `GET /delivery-reports` 的 `preDeliveryContact` 欄位

### 問題描述
前端出貨日報表列印三聯單時，需要讀取客戶的「送前電聯」設定（`preDeliveryContact`），
但目前 `GET /delivery-reports` 回傳的 `items[].customer` 中沒有此欄位。

### 需要修改的位置
檔案：`apps/api/src/modules/delivery-reports/dto/delivery-report-response.dto.ts`

在 `ItemCustomerResponseDto` class 中補上欄位定義：
```typescript
@ApiPropertyOptional({ description: '送前電聯', example: false })
preDeliveryContact: boolean;
```

在 `fromEntity` 中補上對應：
```typescript
preDeliveryContact: entity.preDeliveryContact ?? false,
```

### 前端現況
前端已在 `DeliveryReportSlip.vue` 的 `buildCustomerSlips` 中讀取 `c.preDeliveryContact`，
後端補上後即可自動生效，不需再修改前端。

### 優先度
低（列印三聯單功能，「去前電聯」勾選框目前固定顯示空框）
