# 後端溝通紀錄 — 2026-03-20

### CTI 通話管理 — 後端 API 尚未實作

目前 `cti.service.ts` 中，除了 `handleIncomingCall`（供 voip-relay webhook 呼叫）之外，**所有其他方法皆為 stub，呼叫時直接拋出 `NotImplementedException`（回傳 500）**。

前端已建立 `src/pages/CTI/DataList/DesktopView.vue` 通話記錄頁面及 `src/assets/API/CTI.js`，等待後端實作以下 API：

1. `GET /cti/calls` — 查詢通話記錄列表（需支援以下分頁與篩選）
   - `page`, `limit`：分頁
   - `startDate`, `endDate`：通話日期區間（ISO 8601）
   - `direction`：`INBOUND` | `OUTBOUND`
   - `status`：`RINGING` | `CONNECTED` | `ENDED` | `MISSED`
   - `customerId`：關聯客戶 UUID
   - 回傳格式：`{ data: Call[], total: number, page: number, limit: number }`

2. `POST /cti/calls` — 手動建立通話記錄（前端用於記錄非 VoIP 的電話，如打手機）
   - 必填：`callId`, `direction`, `callerNumber`, `calledNumber`, `status`, `startTime`
   - 選填：`customerId`, `callOutcome`, `notes`

3. `PATCH /cti/calls/:id` — 更新通話記錄
   - 可更新：`customerId`, `callOutcome`, `notes`, `status`

4. `GET /cti/statistics/calls` — 通話統計
   - 篩選：`startDate`, `endDate`, `agentId`

> 注意：`POST /cti/calls` 中的 `callId` 欄位，手動新增時前端會帶入 `"manual-{timestamp}"` 格式，請後端允許此格式或調整為選填。
