## 🌐 前端環境檔說明

前端專案（`egg_crm_vue`）依照不同環境有對應的設定檔與 build 指令。

### 環境檔對照

| 環境檔 | 對應指令 | 連接的 API |
|--------|---------|-----------|
| `.env.development` | `npm run dev` | 測試站（透過本地 proxy 轉發） |
| `.env.staging` | `npm run build:staging` | 測試站（直接連線） |
| `.env.production` | `npm run build` / `npm run build:prod` | 正式站（直接連線） |

### API 位址

| 環境 | API Domain |
|------|-----------|
| 測試站 | `https://staging-api-staging-07d7.up.railway.app` |
| 正式站 | `https://eggdrop.up.railway.app` |

### 說明

- **本地開發（`npm run dev`）**：透過 Vite proxy 將 `/hostApi` 轉發到測試站，避免 CORS 問題
- **`build:staging`**：打包後直接連測試站 API，用於部署測試版前端
- **`build` / `build:prod`**：打包後連正式站 API，用於正式部署
