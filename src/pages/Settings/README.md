# 參數設定模組操作說明

本模組負責系統的基礎參數設定，包含角色管理、權限設定和產品類型設定。

> **注意**：此模組僅在開發環境顯示，正式環境需由系統管理員操作。

## 模組架構

```
Settings/
├── Roles.vue          # 角色設定
├── Permission.vue     # 權限設定
└── ProductType.vue    # 產品類型設定
```

---

## 進入方式

左側選單「參數設定」下：
- **產品類型**：「參數設定」→「產品類型」
- **角色設定**：「參數設定」→「角色設定」
- **權限設定**：「參數設定」→「權限設定」

---

## 一、角色設定

### 功能說明
管理系統中的使用者角色，每個角色擁有不同的權限組合。

### 1.1 預設角色
系統預設以下角色（無法刪除）：

| 角色 | 說明 |
|------|------|
| ADMIN | 系統管理員，擁有所有權限 |
| MANAGER | 管理人員，擁有大部分管理權限 |
| STAFF | 一般員工，擁有基本操作權限 |
| DRIVER | 司機，僅有配送相關權限 |

### 1.2 查看角色列表
- 進入「角色設定」頁面
- 列表顯示：角色名稱、角色代碼、說明、建立日期

### 1.3 新增角色
1. 點擊「新增角色」按鈕
2. 填寫角色資料：
   - **角色名稱**（必填）：顯示名稱
   - **角色代碼**（必填）：英文代碼，如 SALES
   - **說明**：角色的職責說明
3. 設定權限：
   - 勾選該角色可使用的功能
   - 使用權限樹結構選擇
4. 點擊「儲存」

### 1.4 編輯角色
1. 在列表點擊「編輯」按鈕
2. 修改角色資料或權限
3. 點擊「儲存」

### 1.5 刪除角色
1. 在列表點擊「刪除」按鈕
2. 確認刪除

> **注意**：已指派給使用者的角色無法刪除

## 二、權限設定

### 功能說明
管理系統的權限結構，定義各功能模組的存取控制。

### 2.1 權限架構
系統採用「資源-操作」的權限模型：

```
資源 (Resource)
├── CREATE (新增)
├── READ (查看)
├── UPDATE (編輯)
└── DELETE (刪除)
```

### 2.2 系統資源列表

| 資源代碼 | 資源名稱 | 說明 |
|---------|---------|------|
| USER | 員工管理 | 管理員工資料 |
| CUSTOMER | 客戶管理 | 管理客戶資料 |
| VENDOR | 廠商管理 | 管理廠商資料 |
| VEHICLE | 車輛管理 | 管理車輛資料 |
| DRIVER | 司機管理 | 管理司機資料 |
| PRODUCT | 商品管理 | 管理商品資料 |
| ORDER | 訂單管理 | 管理訂單資料 |
| INVENTORY | 庫存管理 | 管理庫存資料 |
| BILLING | 帳務管理 | 管理帳務資料 |
| REPORT | 報表管理 | 查看各類報表 |
| ROLE | 角色權限 | 管理角色和權限 |
| KPI | 儀表板 | 查看 KPI 數據 |

### 2.3 查看權限矩陣
- 進入「權限設定」頁面
- 顯示資源與操作的矩陣表格
- 可查看各角色的權限配置

### 2.4 編輯角色權限
1. 在權限矩陣中選擇角色
2. 勾選/取消勾選對應的權限
3. 系統自動儲存變更

## 三、產品類型設定

### 功能說明
管理系統中的商品分類類型。

### 3.1 預設產品類型

| 類型代碼 | 類型名稱 | 說明 |
|---------|---------|------|
| WATER | 飲水 | 桶裝飲用水（API代碼：BOTTLED_WATER） |
| EGG | 雞蛋 | 各種雞蛋產品 |
| MACHINE | 飲水機 | 飲水機設備 |

### 3.2 查看產品類型
- 進入「產品類型」頁面
- 列表顯示：類型名稱、類型代碼、說明、商品數量

### 3.3 新增產品類型
1. 點擊「新增類型」按鈕
2. 填寫類型資料：
   - **類型名稱**（必填）：顯示名稱
   - **類型代碼**（必填）：英文代碼
   - **說明**：類型說明
3. 點擊「儲存」

### 3.4 編輯產品類型
1. 在列表點擊「編輯」按鈕
2. 修改類型資料
3. 點擊「儲存」

### 3.5 刪除產品類型
1. 在列表點擊「刪除」按鈕
2. 確認刪除

> **注意**：已有商品的類型無法刪除

## 權限說明

| 功能 | 權限代碼 | 說明 |
|------|---------|------|
| 參數設定 | ROLE | 管理系統參數 |

權限操作：
- **CREATE**：新增角色、權限、類型
- **READ**：查看設定資料
- **UPDATE**：編輯設定資料
- **DELETE**：刪除設定資料

## 常見問題

### Q1: 如何讓新員工有特定功能的權限？
1. 建立或選擇適合的角色
2. 在角色中設定所需權限
3. 在員工管理中指派該角色給員工

### Q2: 可以建立自訂角色嗎？
可以，點擊「新增角色」建立符合需求的自訂角色。

### Q3: 權限變更後需要重新登入嗎？
是的，權限變更後需要重新登入才會生效。

### Q4: 如何禁止某員工使用特定功能？
1. 編輯該員工的角色
2. 取消勾選對應的權限
3. 或建立限制權限的新角色指派給該員工

### Q5: 產品類型刪除後商品會怎樣？
已有商品的類型無法刪除，需先移除或轉移該類型下的所有商品。

## 操作建議

### 權限規劃原則
1. **最小權限原則**：只給予必要的權限
2. **角色分類**：依職務建立對應角色
3. **定期檢視**：定期檢視權限配置是否合適

### 新增角色流程
1. 確定角色的職責範圍
2. 列出需要的功能權限
3. 建立角色並設定權限
4. 測試權限是否正確
5. 指派給對應的員工
