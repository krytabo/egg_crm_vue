# 商品管理模組操作說明

本模組負責管理所有產品資料，包含桶裝水、雞蛋、飲水機三大類商品。

## 模組架構

```
Products/
├── WaterPage.vue      # 桶裝水商品管理
├── EggPage.vue        # 雞蛋商品管理
├── MachinePage.vue    # 飲水機商品管理
└── BaseList.vue       # 商品列表共用元件
```

---

## 一、進入商品管理

- **桶裝水資料**：左側選單「商品管理」→「桶裝水資料」
- **雞蛋資料**：左側選單「商品管理」→「雞蛋資料」
- **飲水機資料**：左側選單「商品管理」→「飲水機資料」

---

## 二、商品列表

### 列表資訊
商品列表顯示以下欄位：
- **商品編號**：系統自動產生或自訂
- **商品名稱**：商品顯示名稱
- **單位**：計量單位（桶、箱、台等）
- **售價**：銷售單價
- **成本**：進貨成本
- **庫存數量**：目前庫存
- **狀態**：上架/下架

### 篩選功能
1. **關鍵字搜尋**：輸入商品名稱或編號
2. **狀態篩選**：篩選上架/下架商品
3. 點擊「清除全部搜尋」重置篩選條件

---

## 三、新增商品

### 操作步驟

1. 點擊右上角「新增商品」按鈕
2. 填寫商品基本資料：

#### 基本資訊
| 欄位 | 必填 | 說明 |
|------|------|------|
| 商品編號 | 選填 | 留空則系統自動產生 |
| 商品名稱 | 必填 | 商品顯示名稱 |
| 商品描述 | 選填 | 商品詳細說明 |
| 單位 | 必填 | 計量單位（如：桶、箱、台） |

#### 價格設定
| 欄位 | 說明 |
|------|------|
| 售價 | 銷售給客戶的單價 |
| 成本 | 進貨成本單價 |
| 最低售價 | 可接受的最低銷售價格 |

#### 庫存設定
| 欄位 | 說明 |
|------|------|
| 初始庫存 | 新增時的庫存數量 |
| 安全庫存 | 低於此數量會發出警示 |
| 最大庫存 | 建議最大庫存量 |

#### 其他設定
| 欄位 | 說明 |
|------|------|
| 是否易腐商品 | 標記為易腐品會有額外提醒 |
| 狀態 | 上架/下架 |
| 備註 | 其他注意事項 |

3. 點擊「儲存」完成新增

---

## 四、編輯商品

1. 在列表中找到要編輯的商品
2. 點擊操作欄的「編輯」按鈕
3. 修改需要變更的欄位
4. 點擊「儲存」完成編輯

### 注意事項
- 修改價格不會影響已建立的訂單
- 修改商品編號需謹慎，可能影響報表統計

---

## 五、商品上架/下架

### 下架商品
1. 編輯商品，將狀態改為「下架」
2. 或在列表操作欄點擊「下架」按鈕
3. 下架後的商品不會出現在訂單的商品選擇中

### 上架商品
1. 編輯商品，將狀態改為「上架」
2. 或在列表操作欄點擊「上架」按鈕
3. 上架後即可在訂單中選擇此商品

---

## 六、刪除商品

1. 在列表操作欄點擊「刪除」按鈕
2. 確認刪除提示

### 注意事項
- 已有訂單關聯的商品無法刪除
- 建議使用「下架」取代刪除

---

## 七、商品分類說明

### 桶裝水商品
- 適用於各種容量的桶裝水
- 單位通常為「桶」
- 可設定押瓶金額（如空桶押金）

### 雞蛋商品
- 適用於各種規格的雞蛋
- 單位通常為「箱」或「斤」
- 標記為易腐商品，需注意保存期限

### 飲水機商品
- 適用於飲水機設備
- 單位通常為「台」
- 可設定租賃或銷售模式

---

## 八、庫存管理連動

商品建立後，庫存相關操作請至「庫存管理」模組：
- 查看即時庫存
- 進行入庫/出庫作業
- 庫存調整與盤點

## 權限說明

| 功能 | 權限代碼 | 說明 |
|------|---------|------|
| 商品管理 | PRODUCT | 管理所有商品資料 |

權限操作：
- **CREATE**：新增商品
- **READ**：查看商品
- **UPDATE**：編輯商品
- **DELETE**：刪除商品

## 常見問題

### Q1: 商品編號可以修改嗎？
可以，但建議在沒有相關訂單時才修改，以免影響報表統計。

### Q2: 如何批次匯入商品？
目前系統不支援批次匯入，需逐筆建立商品資料。

### Q3: 刪除商品後庫存資料會怎樣？
刪除商品會同時刪除相關的庫存記錄。若商品有歷史訂單則無法刪除。

### Q4: 如何設定不同客戶的售價？
目前系統使用統一售價，特殊定價請在訂單中手動調整單價。

### Q5: 商品圖片如何上傳？
在編輯商品時，點擊圖片區域即可上傳商品圖片。

---

## 操作技巧

1. **快速搜尋**：使用 Ctrl+F 或搜尋框快速找到商品
2. **排序功能**：點擊表頭可依該欄位排序
3. **複製商品**：可複製現有商品再修改，加快建立速度
