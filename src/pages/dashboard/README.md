# 儀表板模組操作說明

儀表板是系統的首頁，提供各業務維度的 KPI 統計與快速概覽。

## 模組架構

```
dashboard/
├── index.vue       # 入口（根據裝置選擇視圖）
└── DataList.vue    # 儀表板內容（6 個分頁）
```

---

## 進入方式

- 登入後自動進入儀表板
- 或點擊左側選單「儀表板」

---

## 分頁說明

儀表板共分為以下 6 個分頁：

### 1. 總覽（Overview）

顯示整體業務概況：

**摘要卡片**（4 欄）：
| 卡片 | 說明 |
|------|------|
| 待出貨訂單 | 待處理訂單數，含各狀態分布趨勢 |
| 本月營收 | 本月訂單總金額 |
| 活躍客戶 | 有訂單往來的客戶數 |
| 低庫存商品 | 低於安全庫存的商品數量 |

**訂單分類區塊**（顯示 雞蛋訂單 / 飲水訂單，飲水機訂單暫時隱藏）：
- 每個分類顯示：待出貨筆數、最舊未出貨日期
- 點擊可快速前往對應訂單列表

**近期活動**：
- 以表格顯示最近的系統操作紀錄（說明 / 操作者 / 時間）
- 使用 `CustomTinyGrid` 元件實作

---

### 2. 銷售統計（Sales）

分析銷售業績，支援按商品分類或按時間分組查詢。

**摘要卡片**（3 欄）：
| 卡片 | 說明 |
|------|------|
| 總訂單數 | 查詢期間的訂單筆數 |
| 總營收金額 | 查詢期間的訂單總金額 |
| 平均訂單金額 | 總營收 ÷ 訂單數 |

**篩選條件**：
- `商品種類`：使用固定選項（`雞蛋` / `桶裝水` / `飲水機`），直接傳字串至後端 `productCategory` 欄位
- `分組方式`：按日 / 按週 / 按月（對應後端 `groupBy` 參數）
- `開始日期` / `結束日期`

**銷售明細表格**：
- 欄位依 `groupBy` 模式不同而顯示不同時間粒度

---

### 3. 庫存統計（Inventory）

顯示各倉庫庫存現況。

**摘要區塊**（4 欄 × 多列 grid）：
- 每個商品分類顯示：倉庫名稱、目前庫存、安全庫存、狀態

---

### 4. 客戶統計（Customers）

**摘要卡片**（3 欄）：
| 卡片 | 說明 |
|------|------|
| 本月新客戶 | 本月新增的客戶數 |
| Top 客戶數 | 指定期間訂單排名前幾名 |
| 客戶分類數 | 目前客戶標籤類別的種類數 |

**Top 客戶排行表格**：
- 欄位：客戶名稱 / 訂單數 / 總金額

**依類別客戶分布表格**：
- 欄位：分類名稱 / 客戶數量

---

### 5. 儲值統計（Water Deposits）

管理客戶針對各商品的儲值餘額與使用狀況。

> API：`StatisticsWaterDepositsGet` — `GET /statistics/water-deposits`

**摘要卡片**（4 欄）：
| 卡片 | 說明 |
|------|------|
| 涵蓋客戶數 | 有儲值的客戶總數 |
| 儲值總金額 | 所有客戶儲值金額加總 |
| 已使用金額 | 已核銷的儲值金額 |
| 儲值總數量 | 所有商品儲值數量加總 |

**客戶儲值明細（樹狀表格）**：
- 父層：客戶（客戶代碼 / 客戶名稱 / 儲值次數 / 儲值總金額 / 剩餘金額 / 儲值總數量 / 剩餘數量）
- 展開子層：該客戶各商品的儲值明細（相同欄位）
- 使用 `CustomTinyGrid` + `:tree-config="{ children: 'products' }"`

**依商品儲值統計表格**：
- 欄位：商品名稱 / 商品代碼 / 儲值次數 / 儲值總金額 / 剩餘金額 / 儲值總數量 / 剩餘數量
- 資料為前端從 `customers[].products[]` 聚合而來（依 `product.id` 分組加總），按儲值金額降冪排列

---

### 6. 待出貨統計（Pending Shipments）

**摘要卡片**（2 欄）：
| 卡片 | 說明 |
|------|------|
| 待出貨訂單數 | 各狀態的訂單數（趨勢欄位逐一列出） |
| 待出貨總金額 | 所有待出貨訂單的金額加總 |

---

## 卡片 UI 規範

所有摘要卡片統一採用 computed 陣列 + `v-for` 渲染：
```js
const xxxSummaryCards = computed(() => [
  { title: t('key'), value: ..., trend: '...', trendClass: 'text-green-600', icon: markRaw(IconComponent) },
  ...
])
```
- 圖示使用 `lucide-vue-next` 的元件，需以 `markRaw()` 包裝
- 大數字使用 `text-2xl font-bold`
- 趨勢說明使用 `text-sm`，顏色依正/負/中性顯示

---

## 表格高度

所有表格使用 `@vueuse/core` 的 `useWindowSize` 動態計算可視高度：
```js
const { height: windowHeight } = useWindowSize()
const TableScrollY = computed(() => Math.max(windowHeight.value - N, 100))
```
其中 `N` 依各區塊上方佔用空間調整。

## 常見問題

### Q: 儀表板數據多久更新一次？
頁面載入時即時取得，如需更新可重新整理頁面。

### Q: 銷售統計的商品種類搜尋沒有結果？
後端 API 接受的 `productCategory` 值為固定字串（`雞蛋` / `桶裝水` / `飲水機`），前端已改為固定選項下拉，不支援自由輸入。

### Q: 儲值統計的數量不是只有桶裝水嗎？
儲值功能已擴展為可對任意商品儲值，因此所有欄位均使用「數量」而非「桶數」。
