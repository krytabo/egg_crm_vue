# 儀表板模組操作說明

儀表板是系統的首頁，提供重要 KPI 指標和快速概覽。

## 模組架構

```
dashboard/
├── index.vue       # 入口（根據裝置選擇視圖）
└── DataList.vue    # 儀表板內容
```

---

## 進入方式

- 登入後自動進入儀表板
- 或點擊左側選單「儀表板」

---

## 功能說明

### 一、KPI 統計卡片

儀表板上方顯示關鍵業績指標：

| 指標 | 說明 |
|------|------|
| 今日訂單數 | 今天建立的訂單數量 |
| 今日營業額 | 今天的訂單總金額 |
| 本月訂單數 | 本月累計訂單數量 |
| 本月營業額 | 本月累計訂單金額 |
| 待出貨訂單 | 待處理的訂單數量 |
| 低庫存警示 | 低於安全庫存的商品數量 |

### 二、訂單趨勢圖

顯示近期訂單的趨勢變化：
- **時間範圍**：近 7 天 / 近 30 天 / 本月
- **圖表類型**：折線圖
- **數據**：訂單數量和金額

### 三、待處理事項

顯示需要關注的事項：

#### 待出貨訂單
- 列出狀態為「待出貨」的訂單
- 點擊可快速進入訂單管理

#### 庫存警示
- 列出低庫存或缺貨的商品
- 點擊可快速進入庫存管理

#### 待收款項
- 列出尚未收款的請款單
- 點擊可快速進入帳務管理

### 四、快捷操作

提供常用功能的快速入口：
- 新增訂單
- 查看庫存
- 查看報表

## 權限說明

| 功能 | 權限代碼 | 說明 |
|------|---------|------|
| 儀表板 | KPI | 查看 KPI 數據 |

權限操作：
- **READ**：查看儀表板數據

## 常見問題

### Q1: 儀表板數據多久更新一次？
儀表板數據在頁面載入時即時取得，如需更新可重新整理頁面。

### Q2: 可以自訂儀表板顯示的內容嗎？
目前使用預設的儀表板配置，暫不支援自訂。

### Q3: 為什麼某些統計卡片沒有顯示？
可能是權限不足，請確認您的角色是否有對應的查看權限。

### Q4: 圖表數據和報表數據不一致？
- 儀表板顯示的是即時概覽數據
- 詳細報表請至各模組的報表功能查看

## 操作建議

### 每日工作流程
1. 登入後先查看儀表板概覽
2. 處理「待出貨訂單」
3. 關注「庫存警示」，必要時進行補貨
4. 追蹤「待收款項」

### 數據分析
- 觀察訂單趨勢了解業務狀況
- 比較本月與上月的數據變化
- 根據趨勢調整營運策略
