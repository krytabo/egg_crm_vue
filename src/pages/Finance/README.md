# 帳務管理模組操作說明

本模組負責管理公司的帳務作業，包含請款單、折讓單、付款紀錄與帳務報表。

## 模組架構

```
Finance/
├── index.vue           # 入口（根據裝置選擇視圖）
├── DesktopView.vue     # 桌面版視圖
├── MobileView.vue      # 手機版視圖
└── components/
    ├── InvoicesTab.vue   # 請款單 Tab
    ├── CreditsTab.vue    # 折讓單 Tab
    ├── PaymentsTab.vue   # 付款紀錄 Tab
    └── ReportsTab.vue    # 帳務報表 Tab
```

---

## 進入方式
左側選單「帳務管理」→「帳務管理」

頁面包含四個功能頁籤：
1. 請款單
2. 折讓單
3. 付款紀錄
4. 帳務報表

## 一、請款單管理

### 功能說明
管理向客戶請款的單據，可追蹤請款狀態和收款進度。

### 1.1 查看請款單列表
- 切換至「請款單」頁籤
- 列表顯示：請款單號、客戶名稱、請款金額、請款日期、狀態

### 1.2 篩選請款單
| 篩選條件 | 說明 |
|---------|------|
| 日期範圍 | 選擇請款日期區間 |
| 客戶 | 選擇特定客戶 |
| 狀態 | 待處理/已請款/已收款/已取消 |

### 1.3 新增請款單
1. 點擊「新增請款單」按鈕
2. 填寫請款資料：
   - **客戶**（必填）：選擇請款對象
   - **請款日期**：預設今天
   - **付款到期日**：預計收款日期
   - **請款項目**：選擇要請款的訂單或手動輸入項目
   - **備註**
3. 系統自動計算請款金額
4. 點擊「儲存」

### 1.4 請款狀態流程
```
待處理 → 已請款 → 已收款
           ↓
        已取消
```

- **待處理**：請款單已建立
- **已請款**：已向客戶發出請款
- **已收款**：已收到全部款項
- **已取消**：請款單已取消

### 1.5 記錄收款
1. 在請款單列表點擊「收款」按鈕
2. 輸入收款資訊：
   - 收款金額
   - 收款日期
   - 付款方式（現金/轉帳/支票）
   - 備註
3. 點擊「確認」
4. 若全額收款，狀態自動變更為「已收款」

### 1.6 列印請款單
1. 在列表點擊「列印」按鈕
2. 預覽請款單內容
3. 點擊「列印」輸出

## 二、折讓單管理

### 功能說明
管理銷售折讓，用於處理退貨、折扣或價格調整。

### 2.1 查看折讓單列表
- 切換至「折讓單」頁籤
- 列表顯示：折讓單號、客戶名稱、折讓金額、原因、日期、狀態

### 2.2 新增折讓單
1. 點擊「新增折讓單」按鈕
2. 填寫折讓資料：
   - **客戶**（必填）：選擇折讓對象
   - **關聯訂單**：選擇原始訂單（選填）
   - **折讓原因**（必填）：
     - 退貨折讓
     - 價格調整
     - 品質問題
     - 其他
   - **折讓金額**（必填）
   - **說明**
3. 點擊「儲存」

### 2.3 折讓處理流程
```
待審核 → 已核准 → 已沖銷
           ↓
        已駁回
```

- **待審核**：折讓單待主管審核
- **已核准**：審核通過
- **已沖銷**：已完成帳務沖銷
- **已駁回**：審核不通過

### 2.4 審核折讓單
1. 點擊「審核」按鈕
2. 選擇「核准」或「駁回」
3. 輸入審核意見
4. 點擊「確認」

## 三、付款紀錄管理

### 功能說明
記錄所有的收款和付款紀錄，追蹤金流。

### 3.1 查看付款紀錄
- 切換至「付款紀錄」頁籤
- 列表顯示：紀錄編號、日期、類型、對象、金額、付款方式

### 3.2 篩選付款紀錄
| 篩選條件 | 說明 |
|---------|------|
| 日期範圍 | 選擇付款日期區間 |
| 類型 | 收款/付款 |
| 對象 | 客戶或廠商 |
| 付款方式 | 現金/轉帳/支票等 |

### 3.3 新增付款紀錄
1. 點擊「新增紀錄」按鈕
2. 選擇類型：
   - **收款**：向客戶收取款項
   - **付款**：支付給廠商款項
3. 填寫付款資料：
   - **對象**（必填）：客戶或廠商
   - **金額**（必填）
   - **付款日期**
   - **付款方式**：現金/轉帳/支票/其他
   - **關聯單據**：請款單或訂單（選填）
   - **備註**
4. 點擊「儲存」

### 3.4 付款方式說明
| 方式 | 說明 |
|------|------|
| 現金 | 現金收付 |
| 轉帳 | 銀行轉帳 |
| 支票 | 支票付款 |
| 匯票 | 匯票付款 |
| 其他 | 其他付款方式 |

## 四、帳務報表

### 功能說明
提供各種帳務統計報表，協助財務分析。

### 4.1 可用報表
切換至「帳務報表」頁籤，可查看以下報表：

#### 應收帳款報表
- 顯示各客戶的應收帳款餘額
- 帳齡分析（30天內/30-60天/60-90天/90天以上）
- 可匯出 Excel

#### 應付帳款報表
- 顯示各廠商的應付帳款餘額
- 帳齡分析
- 可匯出 Excel

#### 收款統計報表
- 依日期/月份統計收款金額
- 依付款方式分類統計
- 圖表呈現趨勢

#### 銷售統計報表
- 依客戶統計銷售金額
- 依商品統計銷售數量
- 依月份統計銷售趨勢

### 4.2 報表操作
1. 選擇報表類型
2. 設定篩選條件（日期範圍、客戶等）
3. 點擊「查詢」產生報表
4. 點擊「匯出」下載 Excel 檔案

## 常見問題

### Q1: 請款單和訂單的關係？
- 請款單可關聯多筆訂單
- 也可獨立建立不關聯訂單的請款單
- 訂單狀態不會自動影響請款單

### Q2: 如何處理部分收款？
- 在請款單中記錄收款時，輸入實際收款金額
- 系統會追蹤已收和未收金額
- 全額收齊後狀態自動變更

### Q3: 折讓單如何影響帳務？
- 核准的折讓單會產生負數金額
- 可用於沖銷應收帳款
- 會反映在帳務報表中

### Q4: 報表資料可以匯出嗎？
- 是的，點擊「匯出」按鈕可下載 Excel
- 匯出內容依據目前的篩選條件

### Q5: 如何查詢某客戶的所有帳務？
1. 在各頁籤使用「客戶」篩選
2. 或在「帳務報表」查看應收帳款報表

## 操作流程建議

### 日常收款流程
1. 查看「請款單」中的待收款項目
2. 收到款項後，點擊「收款」記錄
3. 核對「付款紀錄」確認入帳

### 月結對帳流程
1. 查看「應收帳款報表」
2. 對照銀行帳戶確認收款
3. 追蹤逾期未收款項

### 退貨折讓流程
1. 在「折讓單」建立退貨折讓
2. 提交審核
3. 核准後沖銷對應的應收帳款
