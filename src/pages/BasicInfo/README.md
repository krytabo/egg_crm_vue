# 基本資料模組操作說明

本模組包含系統的基礎資料管理功能，是其他業務模組的資料基礎。

## 模組架構

```
BasicInfo/
├── Car/          # 車輛管理
├── Customer/     # 客戶管理（含潛在客戶）
├── Driver/       # 司機管理
├── User/         # 員工管理
└── Vendor/       # 廠商管理
```

---

## 一、員工管理 (User)

### 功能說明
管理公司內部員工資料，包含帳號權限設定。

### 操作流程

#### 1. 查看員工列表
1. 點擊左側選單「基本資料」→「員工資料」
2. 系統顯示員工列表，包含：姓名、電話、Email、角色、狀態
3. 可使用搜尋框輸入關鍵字進行篩選

#### 2. 新增員工
1. 點擊右上角「新增員工」按鈕
2. 填寫基本資料：
   - **帳號** (必填)：登入系統使用的帳號
   - **姓名** (必填)：員工姓名
   - **密碼** (必填)：登入密碼
   - **電話**：聯絡電話
   - **Email**：電子郵件
   - **角色** (必填)：選擇員工角色（決定系統權限）
3. 點擊「儲存」完成新增

#### 3. 編輯員工
1. 在列表中找到要編輯的員工
2. 點擊操作欄的「編輯」按鈕
3. 修改需要變更的欄位
4. 點擊「儲存」完成編輯

#### 4. 刪除員工
1. 在列表中找到要刪除的員工
2. 點擊操作欄的「刪除」按鈕
3. 確認刪除提示後完成刪除

### 注意事項
- 員工角色決定其在系統中的權限範圍
- 刪除員工後，該員工將無法登入系統
- 建議定期檢視員工狀態，停用離職人員帳號

## 二、客戶管理 (Customer)

### 功能說明
管理公司的客戶資料，支援公司客戶和個人客戶兩種類型。

### 操作流程

#### 1. 查看客戶列表
1. 點擊左側選單「基本資料」→「客戶資料」
2. 系統顯示客戶列表，包含：
   - 客戶編號、公司/個人名稱
   - 聯絡人、電話
   - 客戶類型（公司/個人）
   - 狀態

#### 2. 篩選客戶
- **關鍵字搜尋**：輸入客戶名稱、電話等關鍵字
- **類型篩選**：選擇「公司」或「個人」
- **狀態篩選**：選擇「啟用」或「停用」
- 點擊「清除全部搜尋」可重置所有篩選條件

#### 3. 新增客戶
1. 點擊右上角「新增客戶」按鈕
2. 選擇客戶類型：
   - **公司客戶**：需填寫公司名稱、統編等
   - **個人客戶**：需填寫個人姓名
3. 填寫基本資料：
   - **客戶名稱** (必填)
   - **聯絡人** (必填)
   - **電話** (必填)
   - **Email**
   - **地址**：可設定多個配送地址
   - **付款條件**：選擇付款方式和信用額度
4. 點擊「儲存」完成新增

#### 4. 管理配送地址
1. 編輯客戶資料
2. 在「配送地址」區塊點擊「新增地址」
3. 填寫地址資訊（城市、區域、詳細地址）
4. 可設定預設配送地址

#### 5. 查看客戶訂單記錄
1. 在列表中點擊客戶名稱或「詳細」按鈕
2. 可查看該客戶的歷史訂單記錄

## 三、潛在客戶管理 (Lead)

### 功能說明
管理尚未成交的潛在客戶，追蹤業務開發進度。

### 操作流程

#### 1. 查看潛在客戶列表
1. 點擊左側選單「基本資料」→「潛在客戶」
2. 系統顯示潛在客戶列表

#### 2. 新增潛在客戶
1. 點擊「新增潛在客戶」按鈕
2. 填寫基本資料：
   - **客戶名稱** (必填)
   - **聯絡人**
   - **電話**
   - **來源**：客戶來源管道
   - **備註**：特殊需求或注意事項

#### 3. 轉換為正式客戶
1. 當潛在客戶確認合作後
2. 點擊「轉換為客戶」按鈕
3. 補充完整客戶資料
4. 系統將自動建立正式客戶資料

## 五、車輛管理 (Car)

### 功能說明
管理公司配送車輛資料，包含車輛基本資訊、保養維修記錄。

### 操作流程

#### 1. 查看車輛列表
1. 點擊左側選單「基本資料」→「車輛資料」
2. 系統顯示車輛列表，包含：
   - 車牌號碼、品牌/型號
   - 燃料類型、載重量
   - 指派司機、狀態

#### 2. 篩選車輛
- **關鍵字搜尋**：輸入車牌、品牌、型號
- **狀態篩選**：可用 / 維修中 / 停用

#### 3. 新增車輛
1. 點擊「新增車輛」按鈕
2. 填寫車輛資料：
   - **基本資訊**
     - 車牌號碼 (必填)
     - 品牌 (必填)
     - 型號 (必填)
     - 出廠年份 (必填)
   - **車輛規格**
     - 車身號碼 (VIN)
     - 引擎號碼
     - 燃料類型：柴油/汽油/電動/油電混合
     - 載重量 (kg)
   - **證照日期**
     - 保險到期日
     - 行照到期日
     - 驗車到期日
   - **備註**
3. 點擊「儲存」完成新增

#### 4. 指派司機
1. 在列表操作欄點擊「指派司機」按鈕
2. 選擇要指派的司機
3. 點擊「確認指派」
4. 如需解除指派，點擊「解除指派」按鈕

#### 5. 查看車輛詳細資料
1. 點擊操作欄的「詳細資料」按鈕
2. 系統開啟車輛詳細資料抽屜，包含三個頁籤：

##### 5.1 保養記錄
- 查看車輛保養歷史
- 點擊「新增保養」記錄保養資訊：
  - 保養類型：換機油、輪胎調換、煞車保養等
  - 費用、執行者/廠商
  - 預定日期、完成日期
  - 保養時里程、下次保養里程
  - 保養說明、備註
- 支援編輯和刪除保養記錄

##### 5.2 維修記錄
- 查看車輛維修歷史
- 點擊「新增維修」記錄維修資訊：
  - 維修類型：引擎、變速箱、煞車系統等
  - 嚴重程度：輕微/中等/嚴重/緊急
  - 維修狀態：待處理/進行中/已完成/已取消
  - 費用、執行者/廠商
  - 報修日期、完成日期
  - 工時、維修說明、備註
- 支援編輯和刪除維修記錄

##### 5.3 行程記錄
- 查看車輛配送行程歷史
- 顯示訂單編號、客戶名稱、配送地址、配送日期、狀態
- 此為唯讀資料，由訂單系統自動產生

## 六、司機管理 (Driver)

### 功能說明
管理公司配送司機資料。

### 操作流程

#### 1. 查看司機列表
1. 點擊左側選單「基本資料」→「司機資料」
2. 系統顯示司機列表

#### 2. 新增司機
請至「員工資料」新增/編輯帳號時，將該帳號的職務設為「司機」即會自動新增到司機列表中

## 權限說明

| 功能 | 權限代碼 | 說明 |
|------|---------|------|
| 員工管理 | USER | 管理員工資料和帳號 |
| 客戶管理 | CUSTOMER | 管理客戶和潛在客戶資料 |
| 廠商管理 | VENDOR | 管理供應商資料 |
| 車輛管理 | VEHICLE | 管理車輛資料 |
| 司機管理 | DRIVER | 管理司機資料 |

每個權限包含以下操作：
- **CREATE**：新增資料
- **READ**：查看資料
- **UPDATE**：編輯資料
- **DELETE**：刪除資料
