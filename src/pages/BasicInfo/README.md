# 基本資料模組操作說明

本模組包含系統的基礎資料管理功能，是其他業務模組的資料基礎。

## 模組架構

```
BasicInfo/
├── Car/          # 車輛管理
├── Customer/     # 客戶管理（含潛在客戶）
├── Driver/       # 司機管理
├── User/         # 員工管理
└── Vendor/       # 廠商管理
```

---

## 一、員工管理 (User)

### 功能說明
管理公司內部員工資料，包含帳號權限設定。

### 操作流程

#### 1. 查看員工列表
1. 點擊左側選單「基本資料」→「員工資料」
2. 系統顯示員工列表，包含：姓名、電話、Email、角色、狀態
3. 可使用搜尋框輸入關鍵字進行篩選

#### 2. 新增員工
1. 點擊右上角「新增員工」按鈕
2. 填寫基本資料：
   - **帳號** (必填)：登入系統使用的帳號
   - **姓名** (必填)：員工姓名
   - **密碼** (必填)：登入密碼
   - **電話**：聯絡電話
   - **Email**：電子郵件
   - **角色** (必填)：選擇員工角色（決定系統權限）
3. 點擊「儲存」完成新增

#### 3. 編輯員工
1. 在列表中找到要編輯的員工
2. 點擊操作欄的「編輯」按鈕
3. 修改需要變更的欄位
4. 點擊「儲存」完成編輯

#### 4. 刪除員工
1. 在列表中找到要刪除的員工
2. 點擊操作欄的「刪除」按鈕
3. 確認刪除提示後完成刪除

### 注意事項
- 員工角色決定其在系統中的權限範圍
- 刪除員工後，該員工將無法登入系統
- 建議定期檢視員工狀態，停用離職人員帳號

## 二、客戶管理 (Customer)

### 功能說明
管理公司的客戶資料，支援公司客戶和個人客戶兩種類型。

### 操作流程

#### 1. 查看客戶列表
1. 點擊左側選單「基本資料」→「客戶資料」
2. 系統顯示客戶列表，包含：
   - 客戶編號、公司/個人名稱
   - 聯絡人、電話
   - 客戶類型（公司/個人）
   - 狀態

#### 2. 篩選客戶
- **關鍵字搜尋**：輸入客戶名稱、電話等關鍵字
- **類型篩選**：選擇「公司」或「個人」
- **狀態篩選**：選擇「啟用」或「停用」
- 點擊「清除全部搜尋」可重置所有篩選條件

#### 3. 新增客戶
1. 點擊右上角「新增客戶」按鈕
2. 選擇客戶類型：
   - **公司客戶**：需填寫公司名稱、統編等
   - **個人客戶**：需填寫個人姓名
3. 填寫基本資料：
   - **客戶名稱** (必填)
   - **聯絡人** (必填)
   - **電話** (必填)
   - **Email**
   - **地址**：可設定多個配送地址
   - **付款條件**：選擇付款方式和信用額度
4. 點擊「儲存」完成新增

#### 4. 管理配送地址
1. 編輯客戶資料
2. 在「配送地址」區塊點擊「新增地址」
3. 填寫地址資訊（城市、區域、詳細地址）
4. 可設定預設配送地址

#### 5. 管理儲值（飲水商品儲值設定）

1. 編輯客戶資料，切換至「**儲值管理**」頁籤
2. 點擊「新增儲值」按鈕新增一筆儲值記錄
3. 填寫儲值資訊：
   - **商品**（必填）：選擇要儲值的商品
   - **儲值數量**：預先儲存的出貨桶數（選填，可擇一填寫）
   - **儲值金額**：預先儲存的金額（選填，可擇一填寫）
4. 儲存後系統將自動初始化「剩餘數量」與「剩餘金額」等於儲值數量與金額

> **提示：** 儲值數量與金額可擇一填寫，也可同時填寫。

##### 儲值扣除業務邏輯

訂單出貨時，系統會**自動扣除**該客戶對應商品的儲值餘額，規則如下：

**兩階段 FIFO 扣除（先數量、後金額）：**

1. **第一階段：優先扣「剩餘數量」**
   - 從最早建立的儲值記錄開始（FIFO），依序從 `remainingQuantity` 扣除本次訂單的出貨數量
   - 直到數量扣完或所有儲值的剩餘數量耗盡為止

2. **第二階段：數量不足時，才扣「剩餘金額」**
   - 若訂單數量超過所有剩餘數量，改從 `remainingAmount` 折算扣除
   - 折算方式：`單價 = 儲值金額 / 儲值數量`，再用出貨數量 × 單價計算應扣金額

**FIFO 原則：** 同一客戶同一商品有多筆儲值時，依建立時間由舊到新依序消耗。

**範例：**

| 儲值記錄 | 儲值數量 | 剩餘數量 | 儲值金額 | 剩餘金額 |
|---------|--------|--------|--------|--------|
| 2026-01（舊） | 10 | 3 | 1,000 | 300 |
| 2026-03（新） | 20 | 20 | 2,000 | 2,000 |

若訂單出貨 8 桶：
- 第一階段：先扣舊記錄的 3 桶 → 再扣新記錄的 5 桶 → 數量扣完
- 結果：舊記錄剩餘數量 = 0，新記錄剩餘數量 = 15

##### 編輯儲值記錄

修改儲值數量或金額時，系統會保留已被訂單消耗的部分，自動重新計算剩餘值：

```
新剩餘數量 = 新儲值數量 - 已被訂單扣除的數量
新剩餘金額 = 新儲值金額 - 已被訂單扣除的金額
（最小為 0，不可為負數）
```

##### 滯留桶數（待後端實作）

> ⚠️ 此功能尚待後端完成 Schema migration 後才會上線。

儲值管理頁面未來將新增「**滯留桶數**」欄位，顯示該商品目前仍在客戶端的實體容器數量。
滯留桶數由訂單系統自動計算：

```
本次滯留數量 = 上一筆訂單的滯留數量 + 本次出貨數量 - 本次回收數量
```

詳細說明請參考：`後端溝通紀錄/2026-03-31.md`

---

#### 6. 查看客戶訂單記錄
1. 在列表中點擊客戶名稱或「詳細」按鈕
2. 系統開啟客戶詳細抽屜，可透過頁籤查看不同類型的歷史訂單：
   - **全部訂單**：顯示所有類別訂單（由 API 回傳，不傳遞 `categoryId`）
   - **飲水訂單**：傳遞 `categoryId: CATEGORY_IDS.WATER` 給 `OrderListGet` API
   - **雞蛋訂單**：傳遞 `categoryId: CATEGORY_IDS.EGG` 給 `OrderListGet` API
3. 點擊訂單列可展開查看該筆訂單的商品明細（使用 CustomTinyGrid 顯示）
4. 訂單狀態顯示使用與訂單管理頁相同的映射規則（`PROCESSING` 顯示為「已出貨-未收款」）

## 三、潛在客戶管理 (Lead)

### 功能說明
管理尚未成交的潛在客戶，追蹤業務開發進度。

### 操作流程

#### 1. 查看潛在客戶列表
1. 點擊左側選單「基本資料」→「潛在客戶」
2. 系統顯示潛在客戶列表

#### 2. 新增潛在客戶
1. 點擊「新增潛在客戶」按鈕
2. 填寫基本資料：
   - **客戶名稱** (必填)
   - **聯絡人**
   - **電話**
   - **來源**：客戶來源管道
   - **備註**：特殊需求或注意事項

#### 3. 轉換為正式客戶
1. 當潛在客戶確認合作後
2. 點擊「轉換為客戶」按鈕
3. 補充完整客戶資料
4. 系統將自動建立正式客戶資料

## 五、車輛管理 (Car)

### 功能說明
管理公司配送車輛資料，包含車輛基本資訊、保養維修記錄。

### 操作流程

#### 1. 查看車輛列表
1. 點擊左側選單「基本資料」→「車輛資料」
2. 系統顯示車輛列表，包含：
   - 車牌號碼、品牌/型號
   - 燃料類型、載重量
   - 指派司機、狀態

#### 2. 篩選車輛
- **關鍵字搜尋**：輸入車牌、品牌、型號
- **狀態篩選**：可用 / 維修中 / 停用

#### 3. 新增車輛
1. 點擊「新增車輛」按鈕
2. 填寫車輛資料：
   - **基本資訊**
     - 車牌號碼 (必填)
     - 品牌 (必填)
     - 型號 (必填)
     - 出廠年份 (必填)
   - **車輛規格**
     - 車身號碼 (VIN)
     - 引擎號碼
     - 燃料類型：柴油/汽油/電動/油電混合
     - 載重量 (kg)
   - **證照日期**
     - 保險到期日
     - 行照到期日
     - 驗車到期日
   - **備註**
3. 點擊「儲存」完成新增

#### 4. 指派司機
1. 在列表操作欄點擊「指派司機」按鈕
2. 選擇要指派的司機
3. 點擊「確認指派」
4. 如需解除指派，點擊「解除指派」按鈕

#### 5. 查看車輛詳細資料
1. 點擊操作欄的「詳細資料」按鈕
2. 系統開啟車輛詳細資料抽屜，包含三個頁籤：

##### 5.1 保養記錄
- 查看車輛保養歷史
- 點擊「新增保養」記錄保養資訊：
  - 保養類型：換機油、輪胎調換、煞車保養等
  - 費用、執行者/廠商
  - 預定日期、完成日期
  - 保養時里程、下次保養里程
  - 保養說明、備註
- 支援編輯和刪除保養記錄

##### 5.2 維修記錄
- 查看車輛維修歷史
- 點擊「新增維修」記錄維修資訊：
  - 維修類型：引擎、變速箱、煞車系統等
  - 嚴重程度：輕微/中等/嚴重/緊急
  - 維修狀態：待處理/進行中/已完成/已取消
  - 費用、執行者/廠商
  - 報修日期、完成日期
  - 工時、維修說明、備註
- 支援編輯和刪除維修記錄

##### 5.3 行程記錄
- 查看車輛配送行程歷史
- 顯示訂單編號、客戶名稱、配送地址、配送日期、狀態
- 此為唯讀資料，由訂單系統自動產生

## 權限說明

| 功能 | 權限代碼 | 說明 |
|------|---------|------|
| 員工管理 | USER | 管理員工資料和帳號 |
| 客戶管理 | CUSTOMER | 管理客戶和潛在客戶資料 |
| 廠商管理 | VENDOR | 管理供應商資料 |
| 車輛管理 | VEHICLE | 管理車輛資料 |
| 司機管理 | DRIVER | 管理司機資料 |

每個權限包含以下操作：
- **CREATE**：新增資料
- **READ**：查看資料
- **UPDATE**：編輯資料
- **DELETE**：刪除資料
