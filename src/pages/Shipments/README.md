# 庫存與報表模組操作說明

本模組負責管理商品庫存和配送報表，包含庫存查詢、異動記錄、調撥、盤點和送貨報表。

## 模組架構

```
Shipments/
├── InventoryPage.vue          # 庫存管理主頁面
├── InventoryMobileView.vue    # 手機版庫存管理
├── DataList/                  # 送貨報表
│   ├── index.vue
│   ├── DesktopView.vue
│   └── MobileView.vue
├── FormPage/                  # 配送單據表單
│   ├── index.vue
│   ├── DesktopView.vue
│   └── MobileView.vue
└── components/
    ├── InventoryOverviewTab.vue    # 庫存總覽
    ├── InventoryMovementsTab.vue   # 異動記錄
    ├── InventoryAlertsTab.vue      # 庫存警示
    ├── InventoryTransferTab.vue    # 庫存調撥
    ├── InventoryReportsTab.vue     # 庫存報表
    └── CycleCountDialog.vue        # 盤點作業
```

---

## 進入方式

- **商品庫存**：左側選單「庫存與報表」→「商品庫存」
- **送貨報表**：左側選單「庫存與報表」→「送貨報表」

# 一、庫存管理

庫存管理頁面包含五個功能頁籤：

## 1. 庫存總覽

### 功能說明
查看所有商品的即時庫存狀況。

### 統計卡片
頁面上方顯示統計資訊：
- **庫存總價值**：所有商品庫存的總價值
- **低庫存項目數**：低於安全庫存的商品數量
- **缺貨項目數**：庫存為零的商品數量
- **待補貨項目數**：需要補貨的商品數量

### 庫存列表
| 欄位 | 說明 |
|------|------|
| 商品編號 | 商品識別碼 |
| 商品名稱 | 商品顯示名稱 |
| 單位 | 計量單位 |
| 目前庫存 | 現有庫存數量 |
| 最低庫存 | 安全庫存設定 |
| 補貨點 | 需補貨的庫存量 |
| 單位成本 | 商品單位成本 |
| 庫存價值 | 目前庫存 × 單位成本 |
| 狀態 | 正常/低庫存/缺貨 |

### 篩選功能
- **關鍵字**：搜尋商品名稱或編號
- **庫存狀態**：全部/正常/低庫存/缺貨

---

## 2. 異動記錄

### 功能說明
記錄所有庫存的入庫、出庫和調整作業。

### 異動類型
| 類型 | 說明 |
|------|------|
| 入庫 (STOCK_IN) | 商品入庫增加庫存 |
| 出庫 (STOCK_OUT) | 商品出庫減少庫存 |
| 調整 (ADJUSTMENT) | 庫存數量調整 |
| 調入 (TRANSFER_IN) | 從其他位置調入 |
| 調出 (TRANSFER_OUT) | 調出到其他位置 |

### 2.1 查看異動記錄
- 切換至「異動記錄」頁籤
- 列表顯示：日期、商品、異動類型、數量、經手人、備註

### 2.2 篩選異動記錄
| 篩選條件 | 說明 |
|---------|------|
| 日期範圍 | 選擇異動日期區間 |
| 商品 | 選擇特定商品 |
| 異動類型 | 入庫/出庫/調整等 |

### 2.3 新增入庫
1. 點擊「入庫」按鈕
2. 填寫入庫資料：
   - **商品**（必填）：選擇商品
   - **數量**（必填）：入庫數量
   - **單位成本**：本次入庫的單位成本
   - **供應商**：選擇供應商（選填）
   - **備註**
3. 點擊「儲存」

### 2.4 新增出庫
1. 點擊「出庫」按鈕
2. 填寫出庫資料：
   - **商品**（必填）：選擇商品
   - **數量**（必填）：出庫數量（不可超過目前庫存）
   - **出庫原因**：銷售/報廢/其他
   - **備註**
3. 點擊「儲存」

### 2.5 庫存調整
1. 點擊「調整」按鈕
2. 填寫調整資料：
   - **商品**（必填）：選擇商品
   - **調整後數量**（必填）：調整後的庫存數量
   - **調整原因**（必填）：盤點調整/損耗/其他
   - **備註**
3. 點擊「儲存」

---

## 3. 庫存警示

### 功能說明
查看需要關注的庫存項目，包含低庫存、缺貨和待補貨。

### 警示類型切換
使用頁面上方的選項切換：
- **低庫存項目**：庫存低於安全庫存
- **缺貨項目**：庫存為零
- **需補貨項目**：已達補貨點

### 列表欄位
| 欄位 | 說明 |
|------|------|
| 商品編號 | 商品識別碼 |
| 商品名稱 | 商品顯示名稱 |
| 目前庫存 | 現有庫存數量 |
| 最低庫存 | 安全庫存設定 |
| 補貨點 | 需補貨的庫存量 |
| 缺口數量 | 需補充的數量 |
| 建議訂購量 | 系統建議的訂購數量 |

### 快速入庫
1. 在列表中點擊「入庫」按鈕
2. 系統自動帶入商品和建議數量
3. 確認後直接完成入庫

---

## 4. 庫存調撥

### 功能說明
在不同倉庫或位置之間調撥庫存。

### 4.1 查看調撥記錄
- 切換至「庫存調撥」頁籤
- 列表顯示：日期、商品、來源位置、目標位置、數量、狀態

### 4.2 新增調撥
1. 點擊「新增調撥」按鈕
2. 填寫調撥資料：
   - **商品**（必填）：選擇要調撥的商品
   - **來源位置**（必填）：選擇調出的位置
   - **目標位置**（必填）：選擇調入的位置
   - **數量**（必填）：調撥數量
   - **備註**
3. 點擊「儲存」
4. 系統自動產生調出和調入記錄

---

## 5. 庫存報表

### 功能說明
提供庫存相關的統計報表。

### 報表類型切換
使用頁面上方的選項切換：

#### 估值報表
顯示庫存的價值統計：
- **篩選**：選擇位置
- **摘要**：總項目數、總數量、總價值
- **列表**：商品、數量、單位成本、總價值

#### 週轉報表
顯示商品的週轉分析：
- **篩選**：選擇日期範圍
- **摘要**：銷售產品數、銷售數量、週轉率、平均庫存天數
- **列表**：商品、銷售數量、平均庫存、週轉率、庫存天數

### 匯出報表
1. 設定篩選條件
2. 點擊「匯出」按鈕
3. 下載 Excel 檔案

---

## 6. 盤點作業

### 功能說明
進行庫存盤點，核對實際庫存與系統庫存。

### 6.1 開始盤點
1. 點擊「盤點作業」按鈕
2. 選擇盤點範圍：
   - **盤點位置**：選擇要盤點的倉庫
   - **盤點人員**：選擇負責人
3. 點擊「開始盤點」

### 6.2 輸入盤點數量
1. 系統列出該位置的所有商品
2. 依序輸入實際盤點數量
3. 系統自動計算差異：
   - 正數：實際多於系統
   - 負數：實際少於系統

### 6.3 完成盤點
1. 確認所有商品都已盤點
2. 檢視差異清單
3. 點擊「完成盤點」
4. 系統自動產生調整記錄

# 二、送貨報表

### 功能說明
查看司機送貨的統計報表。

### 進入方式
左側選單「庫存與報表」→「送貨報表」

### 篩選條件
| 篩選條件 | 說明 |
|---------|------|
| 日期範圍 | 選擇配送日期區間 |
| 司機 | 選擇特定司機 |
| 車輛 | 選擇特定車輛 |

### 報表內容
- **配送統計**：配送單數、完成數、金額
- **司機績效**：各司機的配送數量和完成率
- **配送明細**：每筆配送的詳細資訊

### 匯出報表
1. 設定篩選條件
2. 點擊「匯出」按鈕
3. 下載 Excel 檔案

## 常見問題

### Q1: 入庫和出庫有什麼差別？
- **入庫**：增加庫存（進貨、退貨入庫等）
- **出庫**：減少庫存（銷售、報廢等）

### Q2: 如何處理庫存差異？
1. 進行盤點作業
2. 輸入實際盤點數量
3. 系統自動產生調整記錄

### Q3: 調撥會影響總庫存嗎？
- 不會，調撥只是位置變更
- 總庫存數量維持不變

### Q4: 低庫存警示如何設定？
1. 在商品管理中設定「安全庫存」
2. 庫存低於此數量會出現警示

### Q5: 報表可以自訂嗎？
- 目前使用預設報表格式
- 可匯出後在 Excel 中自訂分析

## 操作流程建議

### 日常庫存作業
1. 查看「庫存警示」處理低庫存
2. 進貨時執行「入庫」作業
3. 出貨時由訂單系統自動出庫

### 週期盤點流程
1. 選擇盤點日期（建議月底）
2. 執行「盤點作業」
3. 核對差異並處理
4. 產生盤點報告

### 異常處理流程
1. 發現庫存差異時
2. 先查看「異動記錄」找原因
3. 確認無誤後執行「調整」作業
4. 記錄調整原因備查
